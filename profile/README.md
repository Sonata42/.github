# Sonata42 Limited

Sonata42 builds software that coordinates AI agents and keeps generated values distinct from measured ones.

Our aim is a provenance-gated runtime for AI agents in critical operational technology.

## What we work on

- **Slot Gateway.** An open-source gateway (Apache 2.0) that gives concurrent AI agents exclusive time slots at shared tools. The protocol is described in a public preprint: https://doi.org/10.5281/zenodo.23753357
- **Measurement integrity.** Information-flow labels attach source and age to critical values, and a gate reports a value only when it has been measured or retrieved.
- **Agent routing.** A routing and protocol layer that lets specialist AI systems find and coordinate with one another, using ideas from Internet routing.
- **Verified multi-agent organisation.** Typed shared records and formal models in the Rocq proof assistant.

Target application areas are maritime, energy and industrial systems.
